  Quick Start Checklist

  Here's what to do in order:

  Day 1: Environment Setup

  Step 1: Install Core Tools
  # Check Node.js is installed
  node --version  # Should show v18.x.x or v20.x.x
  npm --version   # Should show 9.x.x or higher

  # Install Expo CLI globally
  npm install -g expo-cli

  # Verify Expo installation
  expo --version

  Step 2: Install Expo Go on Your Phone
  - Open App Store (iOS) or Google Play (Android)
  - Search "Expo Go"
  - Install it
  - Keep phone and computer on same WiFi network

  Step 3: Initialize Project
  # Navigate to your project directory
  cd C:\Users\kleft\Desktop\decisionCoach

  # Create Expo app with TypeScript template
  npx create-expo-app@latest flow-app -t expo-template-blank-typescript

  # Navigate into the project
  cd flow-app

  # Start the development server
  npx expo start

  Step 4: Test on Your Phone
  - Scan the QR code from the terminal with Expo Go app
  - App should open on your phone
  - You'll see a blank screen with "Open up App.tsx to start working"

  Day 2: Install Project Dependencies

  Once your Expo app is created, install the required packages:

  # Core dependencies for Phase 0
  npm install @nozbe/watermelondb zustand
  npm install react-native-reanimated react-native-gesture-handler
  npm install expo-haptics

  # Development dependencies
  npm install --save-dev @types/react @types/react-native
  npm install --save-dev typescript

  Day 3: Download Rive & Explore

  - Download Rive desktop app
  - Browse community files to see examples
  - Look at state machine examples (how mascot will work)
  - No need to create mascot yet - that's Phase 3

  Setup for Her:
