This is a strategic document designed for a Software Architect and Product Manager. It details the Execution Plan, Tech Stack, and the Mascot Strategy for "Flow.
"Part 1: The Mascot DecisionQuestion: Should the app have a mascot (like Duolingo)?Verdict: YES, but with a specific role.Why?The "Voices" (Lazy Me, Disciplined Me) are internal—they are the user's conflicted thoughts. You need an external entity to be the referee.The Problem: If "Lazy Me" wins too often, the user feels guilty and might avoid the app.The Mascot's Job: To be the non-judgmental "Coach." It is the container for the app. It celebrates the decision process, regardless of the result.Example: If you choose "Netflix" over "Gym," the Mascot doesn't say "You failed." It says, "Cool, enjoy the rest. We'll hit the gym tomorrow."Retention Data: Apps with mascots (Duolingo, Habitica) see up to 3.6x higher retention because users form an emotional bond (parasocial relationship) with the character.Implementation: Do not make 5 mascots. Make ONE mascot (The Guide) who reacts to the 5 Voices.Part 2: Technical Execution Plan1. Mascot Implementation Guide (The "Rive" Strategy)We will not use static images. We will use a State Machine Animation.Step A: Design PhaseCharacter: Abstract creatures work best (e.g., a "Blob," a "Ghost," or a "Cloud"). Avoid humans (too complex to animate emotions).States to Design:Idle: Breathing, looking around.Anticipation (Swipe Start): Eyes follow the user's thumb.Win (Swipe Right): Confetti, smile, jump.Discard (Swipe Left): Shrug, "meh" face, or dodge.Concern: If Stress Level variable is high (from user context).Step B: The Technical HookInstead of playing a video, you map React Native variables to the Rive State Machine:TypeScript// Conceptual Code for Mascot Component
import Rive, { RiveRef } from 'rive-react-native';

const Mascot = ({ swipePosition, stressLevel }) => {
  const riveRef = useRef<RiveRef>(null);

  useEffect(() => {
    // Direct inputs allow 60fps interaction without re-rendering
    if (riveRef.current) {
       // Input 1: Eye tracking (0 to 100 based on swipe X axis)
       riveRef.current.setInputState("State Machine 1", "LookX", swipePosition);

       // Input 2: Emotional state
       riveRef.current.setInputState("State Machine 1", "Stress", stressLevel);
    }
  }, [swipePosition, stressLevel]);

  return <Rive resourceName="mascot" ref={riveRef} />;
};
Result: The mascot looks at the card you are dragging. This subtle interaction makes the app feel "alive."3.
